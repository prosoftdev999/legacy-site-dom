`site.tar` holds `htdocs/`, the server's document root (`/usr/local/apache2/htdocs`), with each file's permission bits and modification time as they were. It was packed without dot-files, so the `.htaccess` files that some directories had are not in it. None of the settings they made depended on anything but a file's directory, its name and its permission bits. The server ran the stock `httpd:2.4.65` Docker image with the `httpd.conf` and `mime.types` in `conf/` in place of the image's own, and its clock was set to UTC.

The trees were captured in one session. Headless Chromium 153.0.8010.12 loaded the URLs in `pages.txt` one after another, in that order, each as a top-level navigation in a fresh browser context, with JavaScript enabled and every host name resolving to that server, and the document was read through the DevTools protocol once it had loaded. `access.log` is the server's log of that session, but only its later part: the log was rotated partway through, and the earlier file was not kept. Chromium was the server's only client, and the order of the requests made while one page was loading means nothing. Every listed URL answered 200. Files the pages refer to that are not in the document root got a 404, so no script ran that could have changed a tree, and nothing in a tree depends on timing.

`known_trees.json` holds the trees of the first 60 URLs in `pages.txt`, in the output format.
