The Tidewater Courier's old site ran on Apache httpd 2.4.65 with server-side includes, and we are moving it to a static host. For every URL in `/app/data/pages.txt` I need the DOM tree that Chromium 153 built when it loaded that URL from the old server. `/app/data/site.tar` is the server's document root as it was, `/app/data/conf/` holds the server's `httpd.conf` and `mime.types`, `/app/data/access.log` is the server's log from the session in which the trees were captured, `/app/data/README.md` says how the pages were loaded, and `/app/data/known_trees.json` has the trees for the first 60 URLs in the format below.

Write `/app/output/page_dom.json` as `{"pages": {...}}`, keyed by the URLs exactly as `pages.txt` lists them, where each value is the list of the document's child nodes. An element is an object with `tag` (its local name), `attrs` (an object of attribute names and values) and `children`. A `template` element has an empty `children` list and a `content` list holding the children of its template contents. An element with a shadow root also has `shadow`, an object with `mode` (`"open"` or `"closed"`) and that root's `children`; shadow roots Chromium creates internally, such as those of form controls, are left out. An `iframe` with a `srcdoc` attribute also has `frame`, the child nodes of the document shown in it; `content` and `frame` are read only on those elements, and any other key is ignored. A text node is a JSON string, a comment is `{"comment": "..."}` and a doctype is `{"doctype": "...", "public": "...", "system": "..."}`. Here is a made-up example:

```json
{"pages": {"http://www.example.com/a.html": [{"doctype": "html", "public": "", "system": ""}, {"tag": "html", "attrs": {"lang": "en"}, "children": [{"tag": "head", "attrs": {}, "children": []}, {"tag": "body", "attrs": {}, "children": ["Hello ", {"comment": " ad slot "}, {"tag": "p", "attrs": {"class": "x"}, "children": ["world"]}]}]}]}}
```

Before comparing, adjacent text nodes are joined in both trees, and then text made only of spaces, tabs, line feeds, form feeds and carriage returns is removed. After that, every URL must be present and every node must match exactly and in order: tags, attribute names and values, text, comments, doctype fields and shadow root modes.

You have 9000 seconds to complete this task. Do not cheat by using online solutions or hints specific to this task.
